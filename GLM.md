# GLM в Claude Code на Mac и Windows

Используем **подписку GLM Coding Plan**: платим за тариф и работаем в пределах включённой квоты. Ключ Z.ai нужен для подключения Claude Code к подписке. Пополнять баланс обычного API не требуется.

Для новичка первый вариант — **попросить Kimi CLI установить и настроить всё за тебя**. Второй — запустить готовый установщик. В обоих случаях вручную редактировать конфиги не нужно.

## Чем хорош GLM

GLM-5.3 стоит попробовать для сложной логики, исправления ошибок и задач, где нужно последовательно изучить проект, изменить код и проверить результат. GLM-5.3-Flash подойдёт для повседневной работы и задач по скриншотам; внутри линейки GLM он расходует меньше кредитов. [Возможности GLM-5.3](https://docs.z.ai/guides/llm/glm-5.3), [возможности Flash](https://docs.z.ai/guides/vlm/glm-5.3-flash).

| Задача | Что выбрать и поручить |
| --- | --- |
| Backend и бизнес логика | GLM-5.3 — реализовать API, обработку данных и проверку ошибок |
| Сложная ошибка | GLM-5.3 — найти причину, воспроизвести и проверить исправление |
| Интерфейс по скриншоту | Flash — разобрать референс и реализовать страницу |
| Скрипты и автоматизация | Flash для простого, GLM-5.3 для сложного — обработать файлы или собрать отчёт |
| Работа с документами | Flash с нужными инструментами — подготовить и проверить результат |

## Перед настройкой: подписка и ключ

1. Зарегистрируйся или войди в [Z.ai](https://z.ai/).
2. Оформи [GLM Coding Plan](https://z.ai/subscribe).
3. В [разделе API Keys](https://z.ai/manage-apikey/apikey-list) создай ключ и скопируй его. Подписка должна быть на том же аккаунте.

Claude Code подключается к **`https://api.z.ai/api/anthropic`** и использует квоту Coding Plan. [Официальная схема подключения](https://docs.z.ai/devpack/tool/claude).

## Вариант 1 — настройка с помощью Kimi CLI

Для этого варианта нужен также аккаунт с доступом к **подписке Kimi Code**: Kimi CLI помогает с установкой и расходует квоту Kimi. После настройки Claude Code работает по твоей **подписке GLM**. Если подписки Kimi нет, переходи сразу к варианту 2 — он требует только GLM Coding Plan.

### Установи Kimi CLI

**На Mac:** открой «Терминал» через Spotlight (`⌘ + пробел`) и вставь:

```bash
curl -fsSL https://code.kimi.com/kimi-code/install.sh | bash
```

**На Windows:** сначала установи [Git for Windows](https://gitforwindows.org/) с обычными настройками. Затем через меню «Пуск» открой **Windows PowerShell** и вставь:

```powershell
irm https://code.kimi.com/kimi-code/install.ps1 | iex
```

Закрой окно терминала после установки и открой новое. Введи:

```text
kimi
```

### Войди в подписку

Внутри Kimi CLI введи `/login`, выбери **Kimi Code (OAuth)** и заверши вход в браузере тем же международным аккаунтом **kimi.ai**, на котором оформлена подписка. Если появится выбор региона, выбирай **Global / International**. Не выбирай **Kimi Platform API key** — это доступ с оплатой за токены. Если браузер не открылся, скопируй показанную ссылку вручную.

[Официальная установка и вход в Kimi CLI](https://www.kimi.com/code/docs/en/kimi-code-cli/guides/getting-started).

### Попроси Kimi всё настроить

Скопируй этот текст целиком **в чат Kimi CLI**, где обычно пишешь задачу:

```text
Помоги установить Claude Code и подключить его к моей подписке GLM Coding Plan от Z.ai. Я обычный пользователь: сам конфиги не редактирую.
Определи мою систему: Mac или Windows. Проверь, установлен ли Claude Code; при необходимости установи его официальным установщиком https://code.claude.com/docs/en/setup.
Используем адрес https://api.z.ai/api/anthropic и ключ аккаунта с активной подпиской GLM Coding Plan из https://z.ai/manage-apikey/apikey-list. Claude Code должен расходовать квоту GLM, а не подключаться к Kimi или обычному API с оплатой за токены.
По умолчанию выбери glm-5.3[1m], контекст 1000000. Для работы со скриншотами предложи glm-5.3-flash[1m]. Настрой также модели для фоновых задач и субагентов.
Создай отдельный профиль GLM и удобную команду запуска claude-glm для моей системы. На Mac она должна запускаться как command claude-glm; на Windows — claude-glm. Учти старые настройки, переменные и алиасы, которые могут мешать подключению.
Ключ попроси через отдельное локальное окно со скрытым вводом. Не проси отправлять его в чат, не выводи его в ответе и не сохраняй в папке проекта.
Сам выполни настройку. Сохрани остальные настройки Claude Code и сделай резервные копии изменяемых файлов. Не отключай проверки разрешений.
Проверь версию Claude Code и подключение коротким запросом. Не объявляй успех, если ключ, тариф или сеть не позволяют его проверить. В конце дай точную команду запуска из папки проекта и объясни, как проверить /status.
Схема подключения: https://docs.z.ai/devpack/tool/claude
```

Подтверждай предлагаемые Kimi действия по установке и настройке. Ключ вводи только в отдельном окне, которое он подготовит. Если Kimi отвечает планом вместо действий, напиши: **«Выполни настройку сам и проверь результат»**.

После завершения введи `/exit`, открой новое окно терминала и используй команду запуска, которую дал Kimi. Если появились ошибки, вернись в Kimi CLI и попроси их исправить.

## Вариант 2 — готовый установщик

Скачай папку с этими инструкциями целиком: **Code → Download ZIP** на GitHub, затем распакуй архив. Писать собственные скрипты не нужно — файлы уже готовы.

**Mac:** открой «Терминал», набери `cd ` с пробелом, перетащи папку с [setup.sh](setup.sh) из Finder и нажми Enter. Выполни:

```bash
zsh setup.sh glm
```

**Windows:** открой распакованную папку с [setup.ps1](setup.ps1) в Проводнике. Набери `powershell` в адресной строке и нажми Enter. Выполни:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1 glm
```

Установщик сам установит Claude Code, если его ещё нет, и предложит выбор:

| Номер | Модель | Когда выбрать |
| --- | --- | --- |
| **1** | GLM-5.3 | Сложная логика и разработка |
| **2** | GLM-5.3-Flash | Повседневная работа и скриншоты, меньший расход квоты |

Если сомневаешься, нажми Enter — будет выбран вариант 1. Для работы по скриншотам выбирай 2: основная GLM-5.3 принимает только текст.

Вставь ключ и нажми Enter. **Символы ключа не появятся на экране — это нормально.** Дождись сообщения «Готово».

## Начни работать после настройки

Открой новое окно терминала в папке своего проекта. На Mac: набери `cd ` с пробелом, перетащи папку из Finder и нажми Enter. На Windows: открой папку в Проводнике, набери `powershell` в адресной строке и нажми Enter.

| Система | Команда запуска |
| --- | --- |
| Mac | `command claude-glm` |
| Windows | `claude-glm` |

После варианта 1 используй точную команду, которую дал Kimi, если она отличается от таблицы.

Если клиент спросит, использовать ли ключ и доверяешь ли ты папке проекта, подтверди для своего проекта.

Внутри Claude Code введи `/status`. Проверь адрес **`https://api.z.ai/api/anthropic`** и выбранную модель. Затем напиши:

> Прочитай README и основные файлы проекта. Объясни, как он устроен, и предложи план работы. Пока не меняй файлы.

Для разработки:

> Реализуй эту функцию в существующей архитектуре. Проверь обработку ошибок, запусти проверки проекта и объясни результат.

Для Flash:

> Изучи приложенный скриншот и реализуй страницу в текущем проекте. Проверь мобильную версию и состояния загрузки, пустого списка и ошибки.

## Как поменять модель или ключ

После варианта 1 попроси Kimi CLI: **«Поменяй модель или ключ подключения Claude Code к GLM и проверь результат»**.

После варианта 2 повтори команду установщика для своей системы. Выбери модель; на вопрос о ключе нажми Enter, чтобы сохранить прежний. Закрой текущую сессию Claude Code и начни новую.

## Если что-то не работает

После варианта 1 можно просто скопировать текст ошибки в Kimi CLI и попросить его проверить подключение. Ключ в сообщение не добавляй.

| Проблема | Что сделать |
| --- | --- |
| Команда запуска не найдена | Открой новое окно терминала после настройки; после варианта 1 попроси Kimi проверить команду запуска |
| Ошибка ключа | Повтори настройку и вставь ключ аккаунта с активным Coding Plan |
| Модель не принимает скриншот | Повтори настройку и выбери Flash |
| Модель с большим контекстом не распознаётся | Обнови Claude Code командой `claude update` (на Mac — `command claude update`) и начни новую сессию |
| Закончилась квота | Проверь остаток и время восстановления в [кабинете Z.ai](https://z.ai/manage-apikey/billing) |

Установщик создаёт настройки автоматически и делает резервные копии изменяемых файлов. Ключ сохраняется локально на твоём компьютере вне папки проекта. [Как работают отдельные настройки запуска](https://code.claude.com/docs/en/settings).

Кредиты входят в подписку. На личном Coding Plan после их исчерпания нет автоматического списания денег с баланса обычного API. Нужно дождаться восстановления лимита или изменить тариф. [Правила подписки](https://docs.z.ai/devpack/faq).

Чтобы подключить Kimi, открой [инструкцию Kimi](KIMI.md).
