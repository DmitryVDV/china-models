# Kimi в Claude Code на Mac и Windows

Используем **подписку Kimi Code**: платим за тариф и работаем в пределах включённой квоты. Ключ подключения нужен для доступа Claude Code к подписке. Отдельно покупать токены Kimi Open Platform не нужно.

Для новичка первый вариант — **попросить Kimi CLI установить и настроить всё за тебя**. Второй — запустить готовый установщик. В обоих случаях вручную редактировать конфиги не нужно.

## Чем хорош Kimi

Kimi стоит попробовать для изучения большого проекта, изменений в нескольких файлах и работы с длинной документацией. K3 с большим контекстом может учитывать больше материалов одновременно. Для небольших правок подойдёт K3 256K. [Возможности Kimi](https://www.kimi.com/code/docs/en/).

| Задача | Что поручить |
| --- | --- |
| Разобраться в чужом проекте | Объяснить структуру, связи между модулями и точки входа |
| Исправить сложную ошибку | Сопоставить логи и код, найти причину и проверить исправление |
| Обновить несколько модулей | Изменить интерфейс и все места его использования |
| Создать интерфейс | Реализовать страницы и состояния по требованиям |
| Автоматизировать работу | Написать скрипт проверки файлов, обработки данных или сборки |

## Перед настройкой: подписка и ключ

1. Войди в [Kimi на kimi.ai](https://www.kimi.ai/) и оформи [подписку с Kimi Code](https://www.kimi.ai/code).
2. Открой **[Kimi Code Console на kimi.ai](https://www.kimi.ai/code/console)** тем же аккаунтом.
3. Нажми **API Keys → Create API Key** и скопируй ключ.

**Важно: используем `kimi.ai` и адрес `https://api.kimi.ai/coding/`.** Этот адрес используется в обоих вариантах настройки. Ключ бери именно в Kimi Code Console; ключ Open Platform и токен входа Kimi CLI для этой настройки не подходят. [Подключение подписки к Claude Code](https://www.kimi.com/code/docs/en/third-party-tools/claude-code.html).

Для работы только в пределах подписки оставь **Extra Usage выключенным**: это отдельное платное продолжение после исчерпания квоты.

## Вариант 1 — настройка с помощью Kimi CLI

### Установи Kimi CLI

**На Mac:** открой «Терминал» через Spotlight (`⌘ + пробел`) и вставь:

```bash
curl -fsSL https://code.kimi.com/kimi-code/install.sh | bash
```

**На Windows:** сначала установи [Git for Windows](https://gitforwindows.org/) с обычными настройками. Затем через меню «Пуск» открой **Windows PowerShell** и вставь:

```powershell
irm https://code.kimi.com/kimi-code/install.ps1 | iex
```

Закрой окно терминала после установки и открой новое. Введи:

```text
kimi
```

### Войди в подписку

Внутри Kimi CLI введи `/login`, выбери **Kimi Code (OAuth)** и заверши вход в браузере тем же международным аккаунтом **kimi.ai**, на котором оформлена подписка. Если появится выбор региона, выбирай **Global / International**. Не выбирай **Kimi Platform API key** — это доступ с оплатой за токены. Если браузер не открылся, скопируй показанную ссылку вручную.

[Официальная установка и вход в Kimi CLI](https://www.kimi.com/code/docs/en/kimi-code-cli/guides/getting-started).

### Попроси Kimi всё настроить

Скопируй этот текст целиком **в чат Kimi CLI**, где обычно пишешь задачу:

```text
Помоги установить Claude Code и подключить его к моей подписке Kimi Code. Я обычный пользователь: сам конфиги не редактирую.
Определи мою систему: Mac или Windows. Проверь, установлен ли Claude Code; при необходимости установи его официальным установщиком https://code.claude.com/docs/en/setup.
Используем международный аккаунт kimi.ai. Адрес Claude Code должен быть строго https://api.kimi.ai/coding/, ключ — из https://www.kimi.ai/code/console. Не подключай Kimi Open Platform с оплатой за токены и не используй OAuth-токен Kimi CLI как ключ Claude Code.
По умолчанию выбери k3-256k, контекст 262144, effort high. Согласуй со мной другой вариант, если он нужен и входит в мой тариф. Настрой также модели для фоновых задач и субагентов.
Создай отдельный профиль Kimi и удобную команду запуска claude-kimi для моей системы. На Mac она должна запускаться как command claude-kimi; на Windows — claude-kimi. Учти старые настройки, переменные и алиасы, которые могут мешать подключению.
Ключ попроси через отдельное локальное окно со скрытым вводом. Не проси отправлять его в чат, не выводи его в ответе и не сохраняй в папке проекта.
Сам выполни настройку. Сохрани остальные настройки Claude Code и сделай резервные копии изменяемых файлов. Не отключай проверки разрешений.
Проверь версию Claude Code и подключение коротким запросом. Не объявляй успех, если ключ, тариф или сеть не позволяют его проверить. В конце дай точную команду запуска из папки проекта и объясни, как проверить /status.
Схема подключения: https://www.kimi.com/code/docs/en/third-party-tools/claude-code.html
```

Подтверждай предлагаемые Kimi действия по установке и настройке. Ключ вводи только в отдельном окне, которое он подготовит. Если Kimi отвечает планом вместо действий, напиши: **«Выполни настройку сам и проверь результат»**.

После завершения введи `/exit`, открой новое окно терминала и используй команду запуска, которую дал Kimi. Если появились ошибки, вернись в Kimi CLI и попроси их исправить.

## Вариант 2 — готовый установщик

Скачай папку с этими инструкциями целиком: **Code → Download ZIP** на GitHub, затем распакуй архив. Писать собственные скрипты не нужно — файлы уже готовы.

**Mac:** открой «Терминал», набери `cd ` с пробелом, перетащи папку с [setup.sh](setup.sh) из Finder и нажми Enter. Выполни:

```bash
zsh setup.sh kimi
```

**Windows:** открой распакованную папку с [setup.ps1](setup.ps1) в Проводнике. Набери `powershell` в адресной строке и нажми Enter. Выполни:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1 kimi
```

Установщик сам установит Claude Code, если его ещё нет, и предложит выбрать модель:

| Номер | Модель | Когда выбрать |
| --- | --- | --- |
| **1** | K3 256K | Начать с обычной разработки; Plus и выше |
| **2** | K3 1M | Большой проект; Pro и выше |
| **3** | K2.8 Preview | Повседневная работа; Plus и выше |
| **4** | HighSpeed | Быстрый вывод ответа; Pro и выше |

Если сомневаешься, нажми Enter — будет выбран вариант 1. Затем вставь скопированный ключ и нажми Enter. **Символы ключа не появятся на экране — это нормально.** Дождись сообщения «Готово».

HighSpeed ускоряет вывод ответа, но расходует больше квоты. Для начала его выбирать необязательно.

## Начни работать после настройки

Открой новое окно терминала в папке своего проекта. На Mac: набери `cd ` с пробелом, перетащи папку из Finder и нажми Enter. На Windows: открой папку в Проводнике, набери `powershell` в адресной строке и нажми Enter.

| Система | Команда запуска |
| --- | --- |
| Mac | `command claude-kimi` |
| Windows | `claude-kimi` |

После варианта 1 используй точную команду, которую дал Kimi, если она отличается от таблицы.

Если клиент спросит, использовать ли ключ и доверяешь ли ты папке проекта, подтверди для своего проекта.

Внутри Claude Code введи `/status`. Адрес подключения должен быть **`https://api.kimi.ai/coding/`**. Затем напиши:

> Прочитай README и основные файлы проекта. Объясни, как он устроен, и предложи план дальнейшей работы. Пока не меняй файлы.

Для практической задачи:

> Найди причину этой ошибки, исправь её и запусти проверки проекта. Объясни, что изменилось и как проверен результат.

## Как поменять модель или ключ

После варианта 1 попроси Kimi CLI: **«Поменяй модель или ключ подключения Claude Code к Kimi и проверь результат»**.

После варианта 2 повтори команду установщика для своей системы. Выбери модель; на вопрос о ключе нажми Enter, чтобы сохранить прежний. Закрой текущую сессию Claude Code и начни новую.

## Если что-то не работает

После варианта 1 можно просто скопировать текст ошибки в Kimi CLI и попросить его проверить подключение. Ключ в сообщение не добавляй.

| Проблема | Что сделать |
| --- | --- |
| Команда запуска не найдена | Открой новое окно терминала после настройки; после варианта 1 попроси Kimi проверить команду запуска |
| Ошибка ключа | Повтори настройку и вставь ключ из Kimi Code Console |
| Нет доступа к 1M или HighSpeed | Выбери K3 256K или проверь тариф |
| Закончилась квота | Посмотри остаток и время восстановления в [Kimi Code Console](https://www.kimi.ai/code/console) |
| После обновления клиента появилась ошибка | Попроси Kimi исправить ошибку или повтори настройку; для обновления Claude Code выполни `claude update` (на Mac — `command claude update`) |

Установщик создаёт настройки автоматически и делает резервные копии изменяемых файлов. Ключ сохраняется локально на твоём компьютере вне папки проекта. [Как работают отдельные настройки запуска](https://code.claude.com/docs/en/settings).

У новых подписок есть окно на 5 часов и общая месячная квота; у старых дополнительно действует недельное окно. Подписка общая для функций аккаунта. [Правила квоты](https://www.kimi.com/code/docs/en/kimi-code/membership.html).

Чтобы подключить GLM, открой [инструкцию GLM](GLM.md).
